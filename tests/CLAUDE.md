# tests/ 규칙

- `test_stepNN_*.py`는 멘토(Claude)가 쓴 수용 테스트다. 스펙 역할을 하므로 학습자는 통과시키려고 이 파일을 고치지 않는다.
- 테스트가 틀렸다고 생각되면 근거를 들어 이의를 제기한다. 맞는 이의라면 멘토가 테스트를 고치고 평가에 좋은 근거로 기록한다.
- 학습자가 더 쓰는 테스트는 `test_<모듈>_extra.py`에 둔다.
- 부동소수 비교는 `pytest.approx` 또는 `math.isclose`.
- `bonus` 마커가 붙은 테스트는 선택 과제다. CI는 `-m "not bonus"`로 돈다.
- 수용 테스트를 새로 쓸 때 멘토는 참조 구현으로 먼저 통과를 확인한다. 참조 구현은 저장소에 넣지 않는다.
