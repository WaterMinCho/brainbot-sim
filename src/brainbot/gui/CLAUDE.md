# gui/ — 화면 계층 규칙 (M2부터)

## 규칙
- 그리기는 core의 상태를 읽기만 한다. gui에서 로봇 상태를 직접 바꾸지 않는다. 키보드 입력은 명령 (v, ω)로 바꿔 core에 넘긴다.
- 월드 좌표와 화면 좌표의 변환은 한 모듈에만 둔다. y축 뒤집기는 거기서만 한다.
- 물리 갱신은 고정 dt, 그리기는 가변 프레임.
- M2~M7은 pygame-ce를 쓴다. 위젯이 많아지는 M8에서 도구를 다시 검토한다.

## 리뷰할 때 확인할 것
1. core가 gui를 import하지 않는가 (의존 방향)
2. 프레임 간격을 물리 계산에 그대로 넣지 않았는가
3. 그리기 함수 안에서 상태를 바꾸지 않는가
4. 픽셀 값이 코드 곳곳에 숫자로 박혀 있지 않은가
