# core/ — 시뮬레이션 코어 규칙

세상, 로봇, 센서의 계산을 맡는다. 화면도 브레인도 모른다.

## 규칙
- 표준 라이브러리만 쓴다. M3부터 numpy를 허용한다. pygame, PySide, rclpy는 import하지 않는다.
- 픽셀 개념이 없다. 모든 값은 월드 좌표(m, rad)다.
- 상태 갱신 함수는 입력을 바꾸지 않고 새 값을 돌려준다.
- 전역 상태와 현재 시각(`time.time()`)을 쓰지 않는다. 시간은 `dt` 인자로만 받는다. 같은 입력이면 항상 같은 결과가 나와야 한다.
- 난수가 필요하면 seed를 가진 `random.Random` 인스턴스를 인자로 받는다.
- 공개 함수는 모두 `tests/`에 테스트가 있다.

## 리뷰할 때 확인할 것
1. 단위가 docstring에 적혀 있는가
2. 각도를 돌려주는 곳에서 정규화했는가
3. 0으로 나누거나 0에 가까운 수로 나누는 곳이 있는가
4. 잘못된 인자(음수 dt, 0 이하의 길이)에 `ValueError`를 던지는가
5. 부동소수를 `==`로 비교하는 곳이 있는가
