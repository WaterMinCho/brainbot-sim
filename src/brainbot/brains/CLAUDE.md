# brains/ — 로봇 판단 로직 규칙 (M5부터)

브레인은 센서 관측을 받아 명령을 돌려준다. 인터페이스는 M5에서 확정한다.

## 규칙
- 브레인은 시뮬레이터의 참값(로봇의 실제 위치, 벽의 좌표)을 읽지 않는다. 센서 관측과 명령 인터페이스만 쓴다. 실제 로봇에서도 같은 코드가 돌 수 있어야 한다.
- 브레인은 core의 자료형만 import한다. gui를 import하지 않는다.
- 틱 한 번의 계산은 dt 안에 끝나야 한다. 오래 걸리는 계산(경로계획, 모델 추론)은 주기를 따로 둔다.
- 브레인 하나는 파일 하나.

## 리뷰할 때 확인할 것
1. 참값에 접근하는 경로가 없는가
2. 같은 관측 순서를 주면 같은 명령 순서가 나오는가 (재현성)
3. 센서 값이 없거나 범위를 벗어날 때의 처리가 있는가
